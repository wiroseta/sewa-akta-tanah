# Sewa & Akta Tanah Manager v1
Prototype PWA untuk pencatatan kontrak sewa, aset/HGB, PIC, rekening bank, pembayaran dan reminder.

## Penting
Versi 1 menyimpan data di localStorage browser. Jangan gunakan sebagai satu-satunya arsip. Dokumen hukum asli jangan disimpan di repository publik.

## GitHub Pages
Upload semua file ke repository, lalu Settings > Pages > Deploy from a branch > main / root.
